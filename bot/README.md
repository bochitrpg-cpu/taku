# 卓日和bot

卓日和（日程調整ツール）で確定したセッションを、Discordの参加者に知らせるbotです。

- **告知**: 卓日和で「確定」を押すと、決めておいたチャンネルに日時が投稿されます（各自のタイムゾーンで表示されます）
- **/次回**: 参加者がこのコマンドを打つと、次のセッションと、そのあとの予定を表示します
- **リマインド**: 開始の前日（24時間前）と1時間前に、同じチャンネルでお知らせします（任意。オフにもできます）

> **動作確認の範囲**: 告知文の読み取り・/次回 の文面・リマインドの判定はテスト（`npm test`）で、卓日和からの送信・書き直し・取り消しはブラウザでDiscordの代わりの偽サーバーを使って確認済みです。**本物のDiscordでの動作は、まだ確認していません。** 最初はテスト用のサーバーかチャンネルで試してください。

## しくみ

```
卓日和（スマホ） ──Webhook──▶ 告知チャンネル ◀──読む── 卓日和bot（PCで常駐）
                                                    ├ /次回 に答える
                                                    └ 時間が来たらリマインドを投稿
```

- 卓日和は、botを経由せず **Discordに直接** 告知を投稿します（Webhook）。そのため、PCが止まっていても告知はできます
- botは、告知チャンネルにある卓日和の投稿を読んで、予定を知ります。予定のデータを別に持たないので、**卓日和で取り消すと告知が消え、botの予定からも消えます**
- 候補日も告知できます（「確定日」タブのカードの「Discordに告知」）。候補日を「確定にする」と、候補日の告知から外れて、確定の告知が新しく出ます
- /次回 とリマインドは、**botが起動しているときだけ** 動きます。止まっている間に過ぎたリマインドは、起動したときに直前のもの1回だけ送ります（開始後なら送りません）

## 必要なもの

- **Node.js 22.13 以上**（[nodejs.org](https://nodejs.org) の LTS 版でOK）
- 起動時に `ExperimentalWarning: SQLite is an experimental feature` と出ますが、害はありません

**Windowsの場合**: PowerShell で `npm` が「スクリプトの実行が無効」と怒られたら、**コマンドプロンプト**（フォルダのアドレス欄に `cmd` と打ってEnter）を使ってください。

## セットアップ

### 1. Discord Developer Portal

[Developer Portal](https://discord.com/developers/applications) で、新しいApplicationを作ります（卓管理botとは別のApplicationにします）。

1. **Bot** タブ: トークンを発行して控える。**Message Content Intent をオンにする**（告知の中身を読むのに使います。100人未満のサーバーなら申請は不要です）
2. **General Information** タブ: Application ID（= Client ID）を控える

### 2. このフォルダ

```bash
copy .env.example .env   # Windows（コマンドプロンプト）。Mac/Linuxは cp。DISCORD_TOKEN と DISCORD_CLIENT_ID を埋める
npm install
npm run invite           # 表示されたURLを開いて、botをサーバーに招待する
```

2回目からは **`start.bat` をダブルクリック** するだけです（初回の `npm install` も自動で行います）。窓を閉じるとbotが止まります。
Windowsにログインしたら自動で起動させたいときは、**`autostart-on.bat`** を一度だけ実行します（やめるときは `autostart-off.bat`）。

### 3. Discordで

1. 告知用のチャンネルで **`/告知先`** を実行する（サーバー管理の権限が要ります）。リマインドでメンションしたいロールがあれば、`ロール` に指定します
2. 返ってきた **Webhook URL** をコピーする（自分にだけ見えるメッセージです。他の人には見せないでください）

### 4. 卓日和で（スマホ）

1. 画面のいちばん下の **「Discord連携」** を開いて、URLを貼り付けて「保存」
2. 「テスト送信」を押して、告知チャンネルに届くか確認する

これで、卓日和で確定するたびに自動で告知されます。

## 設定（.env）

| 項目 | 意味 |
| --- | --- |
| `DISCORD_TOKEN` | botのトークン |
| `DISCORD_CLIENT_ID` | Application ID（招待URLを作るのに使う） |
| `REMIND_MINUTES` | リマインドのタイミング（開始の何分前か、カンマ区切り）。既定は `1440,60`（前日と1時間前）。**空にするとリマインドしません** |
| `DATABASE_PATH` | 告知先の設定とリマインドの送信記録を置くファイル |

## うまく動かないとき

| 症状 | 確認すること |
| --- | --- |
| `/告知先` `/次回` が出てこない | botを起動したか（起動時にコマンドを登録します）。招待URLに `applications.commands` が入っているか（`npm run invite` のURLなら入っています）。Discordアプリを再起動する |
| `/告知先` で「権限がありません」 | そのチャンネルで、botに「チャンネルを見る」「メッセージを送信」「メッセージ履歴を読む」「ウェブフックの管理」があるか |
| `/次回` で「予定されているセッションはありません」 | Developer Portal で Message Content Intent がオンか。告知先チャンネルに卓日和の告知が残っているか（手で消すと、botの予定からも消えます） |
| 卓日和の「テスト送信」が失敗する | URLが `/告知先` で出たものと一字一句同じか。`/告知先` を別のチャンネルでやり直したら、URLも貼り直す |
| ロールのメンションが通知されない | botのロールに「@everyone、@here、全てのロールにメンション」の権限があるか（`npm run invite` のURLなら付いています）。またはそのロールの「このロールに対して@mentionを許可する」をオンにする |

## 制限・注意

- 予定は告知チャンネルの **新しいほうから500件のメッセージ** の中から探します。告知チャンネルはなるべく告知専用にしてください
- 告知チャンネルの卓日和の投稿を手で消すと、その予定は /次回 やリマインドから消えます
- 1つのサーバーにつき、告知先は1チャンネルです

## 構成

```
src/core/sessions.ts  告知文の読み取り・/次回 の文面・リマインドの判定（Discordに触れない純粋関数）
src/db.ts             SQLite（告知先の設定とリマインドの送信記録）
src/index.ts          botの本体（コマンドとリマインドの定期確認）
src/invite.ts         招待URLを出す
test/                 テスト
```
